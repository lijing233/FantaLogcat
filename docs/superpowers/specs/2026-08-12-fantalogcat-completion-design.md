# FantaLogcat 完整首版交付设计

- 状态：已确认，待用户审阅文档
- 日期：2026-08-12
- 目标：完成可测试、可打包、可审阅的 1.0 首版；不创建公开仓库、不推送代码、不发布 GitHub Release。
- 平台：macOS 13+，Apple Silicon（arm64）

## 1. 交付定义

首版让不了解 ADB 的 Unity Android 开发者完成以下真实流程：打开 FantaLogcat，连接或选择 Android 设备，选择一个常用或已安装应用，持续查看其日志，使用内置或自定义筛选定位问题，并将恰当范围的可选脱敏日志导出给团队或 AI 工具。

当前已完成的受管 ADB 准备流程保留：固定官方来源、流式下载、校验、受限解压、已安装文件完整性验证、回滚及符号链接路径防护。受管 ADB 可用后必须自动进入真实设备扫描，而不能停在占位页面。

## 2. 交付顺序

### 2.1 可用主链路

1. `DeviceService` 调用受管 ADB 的 `devices -l`，解析 USB、无线、未授权、离线和多设备状态。
2. 设备页显示自然语言状态与可操作按钮：重新扫描、USB 授权帮助、无线配对、选择设备。
3. `AppCatalog` 读取第三方包，按配置中的常用应用优先排序；支持搜索与临时包名输入。
4. `LogSession` 为已选设备启动唯一的 `logcat -v threadtime` 流，解析、合并多行栈、关联进程/包名并写入有界内存缓存。
5. 主日志界面显示真实状态、暂停显示、继续跟随、清屏、选择与复制。

### 2.2 高效排查与团队复用

1. `FilterEngine` 提供等级、Android Tag、业务 Tag、关键词、排除词、大小写和正则筛选。
2. 公共内置筛选包含：全部、警告、错误、Unity、崩溃/ANR、网络，以及通用业务关键词（`NetworkManager`、`IAA`、`EventTracker`、`TaskManager`、`RewardLogger`、`Withdraw`）。
3. `ConfigurationStore` 支持公共默认、包内团队默认和用户配置三层合并；用户覆盖团队，团队覆盖公共。
4. 配置导入先显示预览（新增、覆盖、跳过、冲突），仅在用户确认后原子写入；配置导出只包含用户显式选择的内容。
5. 团队构建注入 `TeamDefaults.json`；公开构建校验其不存在，且不携带团队包名、域名或预设。

### 2.3 分享与发布准备

1. `ExportService` 从冻结快照生成全部、当前筛选、选中、时间范围或事件上下文范围。
2. 格式为 TXT、JSONL、ZIP 诊断包和面向 AI 的 Markdown；导出前展示条数、时间边界、估算大小、回收提示及脱敏命中数。
3. 脱敏规则为可选项，明确提示不能保证识别所有敏感信息。
4. 提供设置、简体中文/英文、浅深色外观、无障碍标签和本地隐私诊断。
5. 提供构建、未签名 ZIP/DMG、SHA-256、SBOM、公开构建校验、GitHub Actions、README、贡献说明、行为准则、开源许可证及 Release Checklist。发布动作保留给用户在真实设备验收后执行。

## 3. 状态与错误处理

`AppModel` 将状态明确建模为：准备 ADB、扫描设备、需要设备操作、选择设备、加载应用、选择应用、查看日志、可恢复错误。每个异步操作都有加载、成功、失败和重试状态；错误信息使用面向用户的解释并保留可复制的短错误码。任何无设备、无应用、未授权、连接断开或采集异常都必须有可见的下一步，禁止用静态占位文本表示未实现状态。

应用仅保存用户配置与工具自身受限诊断；日志会话只在内存中保存，退出即丢弃，不自动恢复最近会话。

## 4. 界面与 Logo

窗口采用单窗口信息密度适中的结构：顶部为设备、应用、暂停、清屏、导出；中部为筛选条与搜索；主体为高性能日志表；底部为连接、缓存和筛选统计。设备和应用页延续同一视觉语言，以操作按钮替代 ADB 命令。

Logo 为“猫眼终端日志”图形：圆角深海军蓝底，抽象的 `F` 形终端窗同时形成猫耳轮廓，薄荷绿日志轨迹从右侧流出。无文字版用于应用图标和 favicon；带 `FantaLogcat` 字标版用于 README、GitHub 社交图和安装说明。图标需在 16 px 下可识别，因此不使用细小文字、复杂渐变或写实细节。

## 5. 质量门槛

- 每个新领域逻辑先有失败测试，再写最小实现；单元、集成、UI 和真实设备验收覆盖主链路与恢复路径。
- 所有 ADB 参数保持封闭命令模型；用户输入经类型校验；错误输出限长且不泄露无线配对码。
- 日志采集、筛选与导出均不阻塞主线程，缓存同时有数量与字节上限并报告回收。
- 公共 Release 构建只包含公开默认配置；arm64、签名结构、产物校验和文档检查均可自动验证。
- 最终实际发布前，必须在真实 Android 设备上验证 USB、无线、Unity 异常、多小时采集、配置、导出与脱敏。
