# FantaLogcat 1.0.10

## 重要修复

- 修复 1.0.9 在 ad-hoc 签名环境中启动时被 macOS Library Validation 拒绝加载 Sparkle.framework、导致应用立即崩溃的问题。
- 发布流程新增真实应用启动冒烟测试，可捕获 `codesign --verify` 无法发现的 dyld 运行时加载错误。

## 自动更新

- 保留 Sparkle 2.9.4、EdDSA 更新包签名、自动检查和手动“检查更新”功能。
- 1.0.9 无法正常启动，因此需要手动安装一次 1.0.10；之后可通过应用内更新获取新版本。

## 安装说明

- 当前应用仍为 ad-hoc 签名且未经 Apple 公证。首次安装时请在 Finder 中右键 FantaLogcat 并选择“打开”；如果仍被阻止，可使用 DMG 内的“打开隐私与安全性”快捷入口，再点击“仍要打开”。
