# FantaLogcat 1.0.9

## 新功能

- 集成 Sparkle 2.9.4，可在应用菜单或设置页手动检查更新。
- 默认自动检查新版本，并可选择自动下载更新。
- 更新包使用独立 EdDSA 密钥签名，并通过 GitHub Pages Appcast 安全分发。

## 修复

- 修复应用图标四角被错误填充为黑色的问题；所有 AppIcon 尺寸和官网图标现在都使用真实透明背景。

## 说明

- 1.0.8 及更早版本尚未包含自动更新组件，需要手动安装一次 1.0.9；从后续版本开始即可在应用内更新。
- 当前应用仍使用 ad-hoc 签名且未经 Apple 公证，首次打开可能需要在 Finder 中右键选择“打开”。
